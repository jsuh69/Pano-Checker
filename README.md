# Pano-Checker

M5StickS3(ESP32-S3)용 모터 회전수(RPM)·주파수 측정 펌웨어입니다. 마이크 기반 소리 분석, BMI270 진동 분석, 외부 홀 센서 기반 자력 측정을 지원합니다.

현재 버전: **v0.8.0**

## 주요 기능

- 400–600 Hz 대역의 모터 소리를 FFT로 분석해 RPM 표시 (8 kHz, 1024 샘플)
- 내장 또는 I2C 연결 BMI270의 진동 주파수 분석(`VIB` 모드)
- GPIO 1에 연결한 아날로그 홀 센서의 자력 세기(Gauss)와 N/S 극성 표시
- LOW / MID / HIGH / VIB 감도 선택과 AUTO 캘리브레이션
- 주변 소음 대비 피크 신호와 연속 측정 결과를 확인해 순간 충격음·노이즈 억제
- 측정 분석 주기를 500 ms(초당 최대 2회)로 제한
- 20초 무신호 뒤 화면·IMU·마이크를 끄고 CPU를 저전력으로 낮추는 절전 모드

## v0.8.0 변경 사항

- 소음이 큰 곳에서 쓰는 400–600 Hz 모터 대역 탐색, 주변 대역 대비 신호 판정, 연속 주파수 추적을 적용했습니다. LOW/MID/HIGH는 아직 주파수 대역 구분이 아니라 감도 구분입니다.
- 소리 분석은 8 kHz/1024 샘플, 분석 간격은 500 ms로 조정했습니다. 검출에 1–2초 정도 걸릴 수 있습니다.
- 배터리 잔량은 3회 측정값의 중앙값을 표시합니다. USB 연결 중에도 잔량이 떨어지면 숨기지 않고 표시합니다.
- USB 전압 또는 충전 상태 신호로 외부 전원을 확인하고, 연결 중 충전 활성 상태를 주기적으로 재설정합니다. 배터리 숫자 앞에는 USB 연결 시 플러그 아이콘을 표시합니다.
- 기동 시 충전을 활성화하고 모드별로 사용하지 않는 마이크/IMU를 꺼둡니다.
- Arduino IDE가 Windows/macOS 양쪽에서 스케치를 직접 열도록 `.ino`를 동일한 이름의 폴더로 정리했습니다.

> 플러그 아이콘은 외부 USB 전원 감지 표시이며, 실제 배터리 충전 전류를 직접 측정한 표시는 아닙니다. 잔량 % 역시 전압 기반 추정치여서 케이블 탈착 직후 달라질 수 있습니다. 실행 중 순충전 여부와 충전 속도는 실기기에서 확인해야 합니다.

## 조작 방법

| 입력 | 동작 |
| --- | --- |
| BtnA | RPM 측정 모드와 자력 측정 모드 전환 |
| BtnB 짧게 (RPM 모드) | `LOW → MID → HIGH → VIB → LOW` 감도 전환 |
| BtnB 1초 이상 (RPM 모드) | 현재 센서 기준 AUTO 캘리브레이션 |
| BtnB (자력 모드) | 주변 자력 기준선(Baseline) 재보정 |
| 화면이 꺼진 상태의 BtnA/BtnB | 설정 변경 없이 기기 깨우기 |

## 자력 센서 연결

| 센서 핀 | M5StickS3 연결 | 비고 |
| --- | --- | --- |
| VCC | 3.3 V | 5 V 연결 금지 |
| GND | GND | 공통 접지 |
| OUT (아날로그) | GPIO 1 | 자력 측정 입력 |

## macOS에서 이어서 작업하기

Mac의 터미널에서 다음 명령으로 소스를 받습니다.

```sh
git clone https://github.com/jsuh69/Pano-Checker.git
cd Pano-Checker
```

Arduino IDE에서 `M5stickS3-motor-checker/M5stickS3-motor-checker.ino` 파일을 엽니다. 스케치 폴더와 `.ino` 파일 이름이 같으므로 Arduino IDE가 별도 폴더로 복사하지 않아도 됩니다. 이후 변경분은 이 저장소 폴더에서 편집하고 `git status`로 확인하세요.

기존에 Mac에 클론해 둔 저장소가 있다면 해당 폴더에서 `git pull --ff-only`로 업데이트할 수 있습니다. 로컬 수정 사항이 있다면 먼저 백업하거나 커밋하세요.

## 빌드 환경

- 보드: **M5StickS3**
- M5Stack Board Manager: 3.2.5 이상
- M5Unified: 0.2.12 이상
- M5GFX: 0.2.18 이상
- 라이브러리: `arduinoFFT`

Windows와 macOS 모두 Arduino IDE에서 `M5stickS3-motor-checker/M5stickS3-motor-checker.ino`를 열고 보드를 M5StickS3로 선택한 뒤 업로드합니다. USB 시리얼 포트를 선택해야 하며 macOS에서 포트가 보이지 않으면 케이블/USB 권한을 확인하세요.

## 주의 사항

- 화면의 플러그 아이콘은 USB 전압을 우선 사용하며, 충전 상태 핀은 보조 신호로 사용합니다. 실제 충전 전류나 완충 여부를 보증하지 않습니다.
- 배터리 %는 전압 기반 추정치입니다. 케이블 연결/분리로 전압이 바뀌면 표시값도 달라질 수 있습니다.
- 실행 중 빠른 충전이 필요하면 측정을 멈춰 화면이 자동으로 꺼진 절전 상태로 두거나 전원을 끈 뒤 충전하세요.
- RPM 값은 모터의 회전당 음향·진동 주기 수에 따라 달라질 수 있습니다. 회전수와 주파수의 비례 관계가 다르면 해당 기계에 맞춘 보정이 필요합니다.
