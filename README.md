# Pano-Checker

M5StickS3(ESP32-S3)용 모터 회전수(RPM)·주파수 측정 펌웨어입니다. 마이크 기반 소리 분석, BMI270 진동 분석, 외부 홀 센서 기반 자력 측정을 지원합니다.

현재 버전: **v0.7.0**

## 주요 기능

- 150–750 Hz 대역의 모터 소리를 FFT로 분석해 RPM 표시
- 내장 또는 I2C 연결 BMI270의 진동 주파수 분석(`VIB` 모드)
- GPIO 1에 연결한 아날로그 홀 센서의 자력 세기(Gauss)와 N/S 극성 표시
- LOW / MID / HIGH / VIB 감도 선택과 AUTO 캘리브레이션
- 300 ms 연속 신호 확인으로 순간 충격음·노이즈 제거
- 20초 무신호 뒤 화면·IMU·마이크를 끄고 CPU를 저전력으로 낮추는 절전 모드

## v0.7.0 변경 사항

### 안정성

- VIB 모드의 FFT 탐색 범위를 실제 배열 범위로 제한해 I2C 지연 시 메모리 범위 밖 읽기를 방지했습니다.
- FFT 피크 보간 전에 양옆 bin의 존재를 확인하도록 보완했습니다.
- 3축 가속도 크기를 `int16_t`로 잘라 발생하던 오버플로를 제거했습니다.
- I2C 표본이 2개 미만이거나 측정 시간이 비정상일 때 FFT를 중단해 0 나눗셈을 방지했습니다.

### 충전 및 전력 관리

- 기동 시 `M5.Power.setBatteryCharge(true)`를 호출해 펌웨어 실행 중에도 충전이 활성화되도록 했습니다.
- 배터리 전압만으로 USB 연결·충전 상태를 추정하던 로직을 제거하고 M5Unified의 충전 상태 신호만 사용합니다.
- 자력 모드와 절전 모드에서 마이크를 끄고, 오디오 측정 모드로 돌아올 때만 다시 켜도록 해 동작 중 소비전력을 줄였습니다.

> 기기가 켜진 상태에서의 충전 속도는 펌웨어 소비전력과 USB 전원 공급 능력의 영향을 받습니다. 안정적인 데이터/충전 케이블과 5 V / 2 A 이상의 전원 어댑터 사용을 권장합니다.

## 조작 방법

| 입력 | 동작 |
| --- | --- |
| BtnA | RPM 측정 모드와 자력 측정 모드 전환 |
| BtnB 짧게 (RPM 모드) | `LOW → MID → HIGH → VIB → LOW` 감도 전환 |
| BtnB 1초 이상 (RPM 모드) | 현재 센서 기준 AUTO 캘리브레이션 |
| BtnB (자력 모드) | 주변 자력 기준선(Baseline) 재보정 |
| 화면이 꺼진 상태의 BtnA/BtnB | 설정 변경 없이 기기 깨우기 |

## 자력 센서 연결

| 센서 핀 | M5StickS3 연결 | 비고 |
| --- | --- | --- |
| VCC | 3.3 V | 5 V 연결 금지 |
| GND | GND | 공통 접지 |
| OUT (아날로그) | GPIO 1 | 자력 측정 입력 |

## 빌드 환경

- 보드: **M5StickS3**
- M5Stack Board Manager: 3.2.5 이상
- M5Unified: 0.2.12 이상
- M5GFX: 0.2.18 이상
- 라이브러리: `arduinoFFT`

Arduino IDE에서 `M5stickS3-motor-checker.ino`를 열고 보드를 M5StickS3로 선택한 뒤 업로드합니다.

## 주의 사항

- 충전 상태 표시는 M5StickS3 하드웨어의 충전 상태 핀을 사용합니다. 배터리 전압이 높다는 이유만으로 충전 중으로 표시하지 않습니다.
- 실행 중 빠른 충전이 필요하면 측정을 멈춰 화면이 자동으로 꺼진 절전 상태로 두거나 전원을 끈 뒤 충전하세요.
- RPM 값은 모터의 회전당 음향·진동 주기 수에 따라 달라질 수 있습니다. 회전수와 주파수의 비례 관계가 다르면 해당 기계에 맞춘 보정이 필요합니다.
