# Pano-Checker

M5StickS3(ESP32-S3)용 파노 모터 RPM·자력·롤러 속도 측정 및 스톱워치 펌웨어입니다.

현재 릴리즈: [**v0.10.19**](https://github.com/jsuh69/Pano-Checker/releases/tag/0.10.19). 이전 릴리즈 v0.9.1 이후의 변경을 포함합니다.

새 버전의 변경 사항은 README에 버전별 항목을 추가해 기록합니다. 과거 항목은 당시 동작을 설명하며, 현재 사용법은 아래 설명을 기준으로 합니다.

## 최신 버전: v0.10.19 — 속도계 입력 G8 변경

- SPEED 센서 입력을 **G5에서 G8(GPIO8)**로 변경했습니다. 센서 DO를 G8에 연결합니다.
- 속도 계산, 펄스 필터와 다른 모드의 소스는 변경하지 않았습니다. 사용자가 배선 수정 후 동작을 확인했습니다.

## v0.10.18 주요 변경 — 자력 응답 개선·마이크 650Hz 확장

- **자력:** 500ms에서 **100ms(약 10Hz)** 측정 주기로 변경했습니다. 32회 ADC 평균을 유지하고 상승 65%·하강 35% 필터로 반응을 높였습니다. 일정한 상승 입력은 약 3개 표본에서 95% 이상 반영됩니다. 최대 자력을 별도로 고정하는 기능은 아닙니다.
- **마이크 PANO:** LOW/MID/HIGH/AUTO 모두 **300~650Hz**를 탐색합니다. 1024샘플·8kHz FFT, 첫 녹음 프레임 폐기, 단일 프레임 판정을 사용합니다. 연속 프레임·주파수 추적·표시 중앙값 조건은 사용하지 않습니다.
- **VIB:** **150~750Hz**, BMI270 **1600Hz FIFO** 수집과 진동 에너지가 큰 축의 부호 있는 신호 분석을 사용합니다. 사용자가 FIFO 버전의 실기기 동작을 확인했습니다.
- **SPEED:** 외경 **19mm**, 지름 **1.5mm 구멍 1개**, **1펄스/회전**입니다. HIGH가 1ms 유지되면 통과를 확정해 짧은 끊김의 중복 집계를 줄입니다. 실시간 속도와 **MAX 최고 속도**, 앞쪽 버튼 리셋을 제공합니다.
- **전력:** 마이크·VIB FFT는 최대 2Hz로 유지합니다. USB 연결 중에는 감광·화면 꺼짐·슬립을 하지 않습니다. SPD/PWR/EDGE 시리얼 로그와 전환 기록 버퍼는 제거했습니다.

검증: 호스트 회귀 테스트 및 M5StickS3 보드 컴파일 통과. 실제 계측 정확도와 전체 속도 범위는 기준 장비와 별도로 비교해야 합니다. 마이크 기동 안정화를 위해 회당 약 256ms를 녹음하므로, 초기 절전 버전보다 마이크 측정 중 전력 소모가 늘 수 있습니다.

## 조작 방법

v0.9부터 **위쪽 BtnB는 모드 선택**, **앞쪽 BtnA는 현재 모드의 기능 조작**을 담당합니다. 파워 버튼은 기존 전원 기능을 유지합니다.

| 입력 | PANO (파노 측정) | MAGNETIC (자력 측정) | STOPWATCH (스톱워치) | SPEED (속도 측정) |
| --- | --- | --- | --- | --- |
| 위쪽 BtnB | 자력으로 전환 | 스톱워치로 전환 | SPEED로 전환 | 파노로 전환 |
| 앞쪽 BtnA 짧게 | LOW → MID → HIGH → VIB → LOW | 주변 자력 기준선 재보정 | 시작 / 정지 / 이어서 시작 | 현재·최고 속도·펄스 집계 초기화 |
| 앞쪽 BtnA 1초 이상 | 현재 센서의 AUTO 보정 | 주변 자력 기준선 재보정 | 정지하고 0으로 리셋 | 현재·최고 속도·펄스 집계 초기화 |

AUTO에서 앞쪽 버튼을 짧게 누르면 LOW로 돌아옵니다. 짧은 누름은 버튼을 놓을 때 확정됩니다. 스톱워치 시간은 해당 누름이 시작된 시각을 사용합니다. 길게 누른 뒤 놓아도 짧은 누름 동작이 추가 실행되지 않습니다.

화면이 꺼진 상태에서는 어느 버튼이든 첫 조작은 깨우기 전용입니다. 버튼을 놓은 뒤 다시 눌러 기능을 실행합니다. 모드 전환 중 누르고 있던 앞쪽 버튼도 놓기 전까지 새 모드의 동작을 실행하지 않습니다.

화면 상단에 현재 모드와 배터리 잔량·외부 전원 아이콘을 표시하고, 파노에서는 Hz와 감도도 표시합니다.

### 마이크 AUTO / 진동 AUTO 사용 방법

먼저 위쪽 **BtnB**로 `PANO` 모드를 선택합니다. AUTO 종류는 보정을 시작할 때 선택된 센서에 따라 정해집니다.

| AUTO 종류 | 앞쪽 BtnA 조작 | 측정 대역 |
| --- | --- | --- |
| **마이크 AUTO** | 짧게 눌러 `LOW`·`MID`·`HIGH` 중 하나 선택 → **1초 이상 길게 누르기** | 300–650 Hz |
| **진동 AUTO** | 짧게 눌러 `VIB` 선택 → **1초 이상 길게 누르기** | 150–750 Hz |

- `CALIBRATING`이 표시되고 약 1.5초간 보정한 뒤 `AUTO`로 바뀝니다. **보정 중에는 측정할 모터의 소리 또는 진동이 있는 상태를 유지하세요.**
- AUTO에서 BtnA를 **다시 길게 누르면 같은 센서로 재보정**합니다.
- AUTO에서 BtnA를 **짧게 누르면 LOW로 돌아갑니다.** 진동 AUTO에서 마이크 AUTO로 바꾸려면 LOW로 나온 뒤 길게 누릅니다. 마이크 AUTO에서 진동 AUTO로 바꾸려면 LOW로 나온 뒤 짧게 눌러 VIB를 선택하고 길게 누릅니다.
- 두 종류 모두 화면에는 `AUTO`로 표시되므로, 보정 전에 마이크 감도 또는 VIB 중 무엇을 선택했는지 확인하세요.
- AUTO는 피크 크기 기준을 보정하며 센서별 측정 주파수 대역은 바꾸지 않습니다.

## 저전력 동작

| 조건 | 화면 및 전원 정책 |
| --- | --- |
| USB 외부 전원 감지 | 밝기 25/255 유지. 자동 감광·화면 꺼짐·슬립 없음 |
| 배터리, 파노/자력/SPEED에서 5초 무활동 | 밝기 3/255로 감소. 센서 측정은 계속 |
| 배터리, 파노/자력/SPEED에서 20초 무활동 | 화면·마이크·IMU·SPEED 입력 수집을 끄고 CPU light sleep |
| 배터리, 스톱워치 모드 | 마지막 버튼 조작 후 2분간 밝기 유지. 이후 화면을 끄고 light sleep |
| 화면이 켜진 상태에서 버튼 조작 또는 유효 RPM/자력/속도 펄스 검출 | 밝기 복구 및 무활동 시간 초기화 |

- 파노 FFT는 **최대 초당 2회**, 자력 ADC 측정은 **약 초당 10회**입니다. AUTO 보정 중에도 분석 빈도를 높이지 않습니다.
- 마이크는 각 녹음 구간에만 켜고 프레임 사이에는 끕니다. 녹음 완료를 기다린 뒤 FFT를 수행합니다.
- 진동 센서는 VIB/AUTO-VIB에서만 켭니다. 자력·스톱워치·SPEED에서는 마이크와 IMU를 모두 끕니다. SPEED의 G8 인터럽트는 SPEED가 선택되고 화면이 켜진 동안만 연결합니다.
- CPU는 동작 중 80 MHz를 사용합니다. 화면이 꺼지면 클록만 낮추는 루프 대신 RAM을 유지하는 light sleep을 사용합니다.
- FFT는 `float`를 사용하고 Hamming 계수를 기동 시 계산해 재사용합니다. 정지된 화면은 상태·표시값이 바뀔 때 갱신합니다.
- Wi-Fi·Bluetooth·스피커·전원 LED를 사용하지 않습니다. 외부 5V 승압 출력도 기동 시 명시적으로 비활성화합니다.
- 스톱워치 STOPPED 상태는 버튼 확인을 약 50 ms 간격으로 줄이고, 표시 변경이 없으면 화면 갱신 함수를 호출하지 않습니다. CPU는 80 MHz를 유지하며 USB 연결 중에는 슬립하지 않습니다.
- 슬립 중에는 버튼으로 즉시 깨우거나 약 2초마다 USB 전원·배터리 상태를 확인하고 다시 잠듭니다. USB 양성 감지는 첫 표본부터 적용하고, 분리는 3회 연속 확인합니다. 케이블 연결 시 자동으로 화면을 복구합니다.

**센서가 꺼진 슬립 상태에서는 소리로 깨울 수 없습니다.** 소리에 의한 밝기 복구는 마이크 측정이 계속되는 감광 단계에서 유효한 모터 신호를 검출했을 때 동작합니다. VIB에서는 진동 검출을 사용합니다.

스톱워치가 다른 모드에서도 실행 중일 수 있지만, 화면 유지 시간은 현재 선택한 모드의 정책을 따릅니다. USB 연결 중에도 미사용 센서는 계속 꺼둡니다.

> 소비전력 감소량과 실행 중 순충전 여부는 아직 실기기에서 측정하지 않았습니다. USB 감지 아이콘은 실제 충전 전류나 충전 속도를 보장하지 않습니다. 외부 홀 센서의 전원은 GPIO로 제어하지 않으므로 연결 중 자체 소비전류는 남습니다.

## 스톱워치

- 표시: `시:분:초.1/100초`, 실행 중 화면은 최대 초당 10회 갱신합니다.
- 누적 시간은 화면 갱신과 독립적인 64비트 단조 시계로 계산합니다. 표시 자릿수와 실제 버튼 계측 정확도는 다릅니다.
- 모드를 바꾸거나 light sleep에 들어가도 실행 상태와 누적 시간을 유지합니다.
- 앞쪽 버튼을 길게 누르면 실행 중에도 정지·리셋합니다.
- 전원 종료·재부팅 시 기록은 초기화됩니다.

## SPEED: LM393 롤러 속도 측정

| 센서 핀 | StickS3 연결 | 비고 |
| --- | --- | --- |
| DO | G8 / GPIO8 | 3.3V 로직, INPUT_PULLUP |
| GND | GND | 공통 접지 |
| VCC | 모듈 사양에 맞는 전원 | 현재 사용 모듈은 3.3V 공급으로 시험 |

센서 출력은 **구멍 열림=LOW(LED 켜짐), 가림=HIGH(LED 꺼짐)**입니다. G8에는 5V 신호를 직접 입력하지 않습니다. 외부 5V 승압 출력은 절전 정책에 따라 꺼둡니다.

CHANGE 인터럽트에서 LOW/HIGH를 관찰합니다. LOW를 본 뒤 HIGH가 **1ms 이상** 유지돼야 통과를 확정합니다. 중간에 HIGH가 1ms 미만으로 끊겼다가 LOW로 돌아오면 같은 통과로 묶습니다. 정상 HIGH 구간까지 1ms보다 짧아지는 속도에서는 누락될 수 있으며, 모든 형태의 잡음을 제거하는 것은 아닙니다.

```text
롤러 원주 = π × 0.019 ≈ 0.059690m
RPM = 유효 펄스 수 × 60000 / 실제 경과 시간(ms)
속도(km/h) = 유효 펄스 수 / 실제 경과 시간(s) × π × 0.019 × 3.6
```

약 **500ms마다** 실제 경과 시간으로 계산합니다. 화면 중앙은 실시간 속도, 하단은 **MAX 최고 속도**입니다. 최고 속도는 더 높은 집계값이 나오면 갱신하고 정지·절전·모드 전환 시 유지합니다. 앞쪽 버튼 짧게/길게 모두 현재·최고 속도와 펄스 집계를 초기화합니다. 재부팅 시 최고 속도는 0이며 플래시에 저장하지 않습니다. 스톱워치 상태는 바꾸지 않습니다.

500ms 구간에서 1펄스 차이는 약 0.430km/h입니다. 사용자 시험에서 한 방향 10회전이 10회로 검출되고 약 28km/h가 안정적으로 표시됐지만, 이는 절대 정확도나 최대 사용 속도의 보장을 뜻하지 않습니다. 실제 접촉 외경·미끄러짐·센서 정렬에 따라 오차가 생길 수 있습니다. 현재 버전에는 R/A 누적 화면이나 SPD/EDGE 시리얼 진단이 없습니다.

## 모드별 측정 주파수 대역

아래는 현재 소스에 설정된 **피크 탐색 대역**입니다. LOW/MID/HIGH는 대역 선택이 아니라 검출 감도 선택이며, 모두 **300–650 Hz로 좁힌 동일 대역**을 사용합니다.

| 모드 / 옵션 | 센서 | 피크 탐색 대역 | 검출 조건 |
| --- | --- | --- | --- |
| PANO / LOW | 마이크 | **300–650 Hz** | FFT 피크 25,000 이상, 단일 프레임 판정 |
| PANO / MID | 마이크 | **300–650 Hz** | FFT 피크 15,000 이상, 단일 프레임 판정 |
| PANO / HIGH (기동 기본값) | 마이크 | **300–650 Hz** | FFT 피크 8,000 이상, 단일 프레임 판정 |
| PANO / VIB | BMI270 가속도 | **150–750 Hz** | 진동 피크 크기 및 300 ms 이상 연속 검출 조건 |
| PANO / AUTO (마이크에서 보정) | 마이크 | **300–650 Hz** | 보정한 피크 크기 범위, 단일 프레임 판정 |
| PANO / AUTO (VIB에서 보정) | BMI270 가속도 | **150–750 Hz** | 보정한 피크 크기 범위 및 300 ms 이상 연속 검출 조건 |
| MAGNETIC | GPIO 1 아날로그 홀 센서 | 주파수 분석 없음 | 주변 기준선 대비 자력과 N/S 극성 표시 |
| STOPWATCH | 센서 사용 안 함 | 주파수 분석 없음 | 시간만 계산하며 FFT·진동·자력 측정은 실행하지 않음 |
| SPEED | LM393 디지털 DO / G8 | FFT 대역 제한 없음 | CHANGE 관찰, HIGH 1ms 안정화 후 통과 집계 |

- 마이크의 지역 잡음 SNR 및 연속 프레임 판정을 제거했습니다. 위 FFT 크기는 물리적인 음압 단위가 아니며 실제 환경에서 확인이 필요합니다.
- AUTO는 보정할 때 사용한 센서와 그 센서의 탐색 대역을 유지합니다. 주파수 대역을 자동 탐색하거나 넓히지 않습니다. VIB를 선택한 뒤 앞쪽 버튼을 길게 누르면 AUTO-VIB가 됩니다.
- 분석은 최대 초당 2회입니다. 마이크는 조건을 만족하는 첫 프레임부터 표시합니다. 연속 녹음은 하지 않으므로 녹음 구간 사이 소리의 지속 여부를 판정하지 않습니다.
- VIB의 150–750 Hz는 목표 탐색 대역입니다. 실제 수집 속도에서 분석 가능한 FFT bin 범위로 제한됩니다. 300 ms 연속 조건 역시 분석 프레임에서 확인하므로 300 ms마다 결과를 갱신한다는 뜻은 아닙니다.
- 대역 설정 위치: 스케치의 `Audio::kMicTargetBandLoHz/HiHz`(마이크), `processAudioAndFFT()`의 `searchBandLoHz/searchBandHiHz`(VIB).

## 측정 방식과 해석

- 마이크는 8 kHz / 1024 샘플을 수집하고 평균 제거·Hamming 윈도·FFT·피크 보간을 적용합니다.
- VIB는 BMI270의 1600Hz FIFO에서 XYZ 512개를 수집합니다. DC 제거 후 진동 에너지가 큰 축을 선택하고 Hamming 윈도·1024개 zero padding을 적용합니다. 주파수 기준은 호스트 읽기 시간이 아닌 센서 ODR입니다.
- RPM은 `Hz × 60`입니다. 마이크의 300–650 Hz는 이 환산 기준으로 18,000–39,000 RPM에 해당합니다. 모터별 회전당 음향·진동 주기 수가 다르면 별도 보정이 필요합니다.
- AUTO는 약 1.5초간 보정 당시 피크 평균의 0.5배/3배를 하한/상한으로 설정합니다. 무신호 보정으로 잘못된 기준을 만들지 않도록 실제 검출 대상 신호가 있는 상태에서 보정하고 결과를 확인하세요.
- 자력은 GPIO 1의 32회 ADC 평균과 주변 기준선 차이를 사용합니다. Gauss 계수 `0.872`와 N/S 표시는 연결 센서·장착 방향에 맞춰 실측 검증해야 합니다.
- 배터리 %는 최근 3회 잔량의 중앙값입니다. 전압 기반 추정치이므로 USB 탈착 직후 바뀔 수 있습니다. 현재 라이브러리 계산에서는 약 4.10 V부터 100%로 표시되며, 표시 100%가 충전 종료를 뜻하지 않습니다. 펌웨어는 충전을 허용하고, 실제 종료는 충전 IC가 판단합니다.

### v0.10.19 속도계 센서 입력 변경

- 센서 DO 입력을 G5(GPIO5)에서 **G8(GPIO8)**로 변경했습니다. 인터럽트 및 펄스 집계 로직은 그대로 유지합니다.
- 배선 수정 후 사용자 실기기 동작 확인.

### v0.10.18 자력 응답·마이크 대역 확대

MAGNETIC은100ms(약10Hz)마다32회 ADC 평균을 측정하며 상승65%·하강35% 필터를 적용합니다. 일정한 자력 상승은 약3회 표본(약300ms)으로95% 이상 반영합니다. 최고값을 영구 고정하는 기능은 아니며 실시간 자력 반응을 높인 것입니다. 영점 보정은1초를 유지합니다. 마이크 LOW/MID/HIGH/AUTO는300~650Hz로 확대했습니다. 마이크·VIB FFT는 최대2Hz, VIB150~750Hz 및 전력·SPEED정책은 유지합니다. 이하 과거500ms자력주기·600Hz상한설명은 현재버전에 적용되지 않습니다.

### v0.10.17 VIB FIFO 수집

1600Hz의 개별 샘플을I²C로 쫓아 읽는 대신 BMI270 FIFO에 쌓인 가속도512표본을16표본(96바이트)씩 읽습니다. FFT 샘플링 속도는 I²C 처리 시간이 아닌 센서 설정1600Hz를 사용합니다. 읽기·버튼 처리 지연이 있어도 FIFO가 넘치지 않으면 일정 간격 표본을 유지합니다. FIFO가 가득 찬 경우만 VIB RETRY로 폐기하며, 통신 실패·데이터 공급 정지는 SENSOR ERROR로 처리합니다. signed축 분석·기존 대역·마이크·SPEED는 유지합니다. 이하 과거 개별 읽기 간격 검사는 현재 버전에 적용되지 않습니다.

### v0.10.16 VIB 전원 설정·오류 구분

VIB 활성화 시 BMI270의 고급 절전(APS)을 해제하고1600Hz 가속도 설정·기동 대기를 적용합니다. VIB 해제 후 가속도를 끄고 APS를 복구합니다.512표본 수집 중 버튼/I²C 관리 처리를 하지 않고 프레임 뒤에서 처리합니다(버튼 응답은 수집 시간 약320ms만큼 늦을 수 있음). 타이밍이 불규칙한 프레임은 SENSOR ERROR 대신 VIB RETRY로 표시해 재시도하며 잘못된 FFT 값은 사용하지 않습니다. 센서 부재·I²C 실패·데이터 준비 타임아웃은 실제 오류로 유지합니다. 마이크·SPEED는 변경하지 않았습니다.

### v0.10.15 VIB 수집·FFT 수정

BMI270의 새 가속도 데이터 준비 플래그를 확인해512개를 수집합니다. XYZ 크기 합성 대신 DC를 제거한 가장 큰 진동 에너지 축의 부호 있는 신호를 FFT에 사용해 주파수 배증 가능성을 줄입니다. 샘플 누락이 의심되는 긴 간격이나1600Hz 설정과 맞지 않는 프레임은 표시하지 않습니다. VIB/AUTO-VIB150~750Hz·300ms 판정은 유지하고 마이크·SPEED는 변경하지 않았습니다. 고정 상태에서 모터와 센서를 단단히 접촉해야 하며 기구 공진·배음이 남을 수 있습니다. 실기기 정확도 검증은 별도입니다.

### v0.10.14 주파수 발생기 검증용 마이크 경로

최근 3표본 중앙값 표시를 제거하고 현재 FFT 주파수를 바로 표시합니다. 각 마이크 기동 후 첫1024샘플(128ms)을 버리고 다음 프레임을 분석해 기동 과도응답 영향을 줄입니다. LOW/MID/HIGH에서 큰 FFT 피크를 일괄 거부하던 고정 상한을 제거했습니다. AUTO 보정 범위와 진동 판정은 유지합니다. 300~600Hz·8kHz/1024·최대2Hz 분석을 유지합니다. 마이크는 분석 사이 OFF지만 녹음 시간이 회당 약128ms에서256ms로 늘어 마이크 측정 중 소비전류는 이전보다 증가할 수 있습니다. 이 변경이 실기기 문제의 원인을 확정한 것은 아닙니다. 아래 과거 버전 중앙값 설명은 현재 적용되지 않습니다.

### v0.10.13 마이크 감도·표시 안정화

LOW/MID/HIGH 피크 기준을 100000/50000/25000에서 25000/15000/8000으로 낮췄습니다. LOW도 이전 HIGH 수준의 약한 소리를 검출합니다. 마이크 화면은 최근 유효 주파수 3개의 중앙값으로 한 번 튀는 값을 억제합니다. 첫 검출은 즉시 표시하고 무검출·모드/감도 변경 시 이력을 초기화합니다. 지속적인 주파수 변화는 새 값 2회 이후 반영될 수 있습니다(약0.5~1초). 검출 자체에는 연속 프레임·SNR 조건을 재도입하지 않았습니다. AUTO 보정·진동·2Hz 분석·절전은 유지합니다. 중앙값은 표시 안정화이며 실제 모터 기본 주파수 식별을 보장하지 않습니다.

### v0.10.12 마이크 판정 단순화·300Hz 확장

마이크 LOW/MID/HIGH/AUTO의 SNR·연속 프레임·±18Hz 추적 조건을 제거하고 단일 프레임 피크로 판정합니다. LOW/MID/HIGH는 피크 크기 기준으로 감도를 구분하며 AUTO 보정 범위는 유지합니다. 마이크 대역은 300~600Hz, 진동은 기존 150~750Hz 및 300ms 판정을 유지합니다. 분석은 최대 2Hz, 마이크는 녹음 사이 OFF, USB 화면 정책·SPEED·최고 속도·리셋·로그 제거는 유지합니다. 새 판정은 일시적인 대역 내 소리도 감지할 수 있습니다.

### v0.10.11 현재 속도·최고 속도·리셋

SPEED 중앙에 실시간 속도(km/h), 하단에 MAX 최고 속도를 표시합니다. 기존 R/A 진단 누적 표시를 MAX로 교체했습니다. 최고 속도는 약 500ms마다 계산한 속도가 기존 기록보다 높을 때만 갱신하며 정지·절전·모드 전환 후에도 유지합니다. 앞쪽 BtnA를 짧게 누르거나 1초 이상 길게 누르면 현재 속도·최고 속도·펄스 누적값을 모두 초기화하고 다시 측정합니다. 전원 재시작 시 최고 기록은 0이며 영구 저장하지 않습니다. SPD/PWR/EDGE 로그와 진단 기록은 제거한 상태입니다. 이하 과거 버전의 R/A 화면·시리얼 설명은 현재 버전에 적용되지 않습니다.


### v0.10.10 로그 제거

SPD·PWR·EDGE 시리얼 출력, 전환 기록 버퍼, 진단용 전원 레지스터 조회와 Serial 초기화를 제거했습니다. 외경 19mm·1펄스/회전·HIGH 1ms 안정화 판정과 화면 R/A 누적 표시는 유지합니다. 사용자가 10회전=10회 검출 및 약 28km/h의 일정한 표시를 확인했습니다. 절대 정확도나 전체 속도 범위의 검증을 의미하지는 않습니다. 아래 과거 버전의 시리얼 로그 설명은 현재 버전에 적용되지 않습니다.

### v0.10.9 현재 통과 판정

외경 19mm·구멍 1개·1펄스/회전을 유지합니다. LOW를 관측한 뒤 HIGH가 1000μs 이상 유지되면 통과 1회로 확정합니다. 중간 HIGH가 1000μs 미만으로 끝나고 다시 LOW가 되면 같은 통과로 묶습니다. 이전의 상승 에지 간격 1ms 필터와 다릅니다. 짧은 LOW는 폭만으로 제외하지 않습니다. ISR과 메인 루프가 동일한 잠금으로 상태를 공유하고 루프가 늦어져도 다음 LOW에서 이전 통과를 확정합니다.

SPD 설정 표시는 `high_us=1000`입니다. raw/R은 원시 HIGH 진입 수, pulses/A는 확정된 통과 수입니다. EDGE의 `candidate=2`는 HIGH 안정화를 기다리는 후보이며 최종 수락이 아닙니다. 0은 후보 없는 에지입니다. 기존 accept 필드는 제거했으며 정지 후 전환 로그 출력은 유지합니다.

1ms는 시험용 조건입니다. 중복 신호 사이 HIGH가 1ms 이상이면 별도 통과로 집계되므로 모든 중복을 제거하지는 못합니다. 정상 HIGH도 1ms 미만인 고속에서는 누락될 수 있습니다. 초기화 후 한 방향으로 정확히 10바퀴 돌려 A=10인지 확인한 뒤 기준 속도와 비교해야 합니다.


### v0.10.9 변경

- **지름 19mm, 지름 1.5mm 구멍 1개** 롤러에 맞춰 환산했습니다. 1회전당 1펄스이며 구멍 크기는 계산식에 사용하지 않습니다.

- 사용자 요청에 따라 PCNT 대신 **attachInterrupt(CHANGE)**으로 G5 양쪽 전환을 관찰하고 HIGH 진입만 속도로 집계합니다. ISR은 micros 시각과 정수 카운터를 사용해 짧은 HIGH 끊김을 같은 LOW 통과로 묶고 HIGH가 1ms 이상 유지될 때 확정합니다. 레벨·시각을 고정 버퍼에 기록하며 시리얼·속도 계산은 하지 않습니다.
- 메인 루프에서 millis 기준 **500ms마다** 실제 경과 시간과 누적 카운트 차이로 롤러 RPM·km/h를 계산합니다. 시리얼 출력은 약 1초마다 비차단 방식으로 수행합니다.
- 입력 극성은 기둥 가림=HIGH, 구멍 열림=LOW이며 상승만 1회/회전으로 집계합니다. 양쪽 에지를 모두 세지 않습니다.
- 1ms 중복 에지 필터를 추가했습니다. SPEED의 앞쪽 버튼은 **짧게/길게 모두 측정 초기화**이며 화면에 IRQ와 R(원시 누적)/A(유효 누적)를 표시합니다.
- 모드 이탈·절전 시 인터럽트를 해제합니다. USB 연결 시 기존 화면·측정 유지 정책을 따릅니다.

- 모드 순환은 **PANO → MAGNETIC → STOPWATCH → SPEED → PANO**입니다. SPEED는 진입 즉시 측정하며 앞쪽 버튼으로 조작합니다.
