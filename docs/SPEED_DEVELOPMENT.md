로그 없는 v0.10.10에 실시간 속도와 MAX 최고 속도 표시를 추가했다. 최고는 500ms 집계 결과의 최댓값이다. 정지·절전·모드 전환에서는 유지하고 앞쪽 버튼 짧게/길게 또는 재부팅 시 초기화한다. 플래시 저장은 하지 않는다. 화면 R/A 대신 MAX를 표시한다. 검출 알고리즘은 19mm·1펄스/회전·HIGH 1ms 안정화를 유지한다. 이하 이전 구현 참고 기록이다.

# v0.10.10 현재 상태

시리얼 로그·전환 기록·진단 큐·진단 전원 조회를 제거했습니다. 19mm·1펄스/회전·HIGH 1ms 안정화 판정과 R/A 누적 화면은 유지합니다. 호스트 테스트는 시리얼 연결 상태에서도 출력과 진단 버스 조회가 없는지 검증합니다. 이하 내용은 이전 구현의 참고 기록입니다.

# SPEED 모드 개발 가이드 (v0.10.9)

## v0.10.9 현재 통과 판정

외경 19mm·구멍 1개·1펄스/회전을 유지합니다. LOW를 관측한 뒤 HIGH가 1000μs 이상 유지되면 통과 1회로 확정합니다. 중간 HIGH가 1000μs 미만으로 끝나고 다시 LOW가 되면 같은 통과로 묶습니다. 이전의 상승 에지 간격 1ms 필터와 다릅니다. 짧은 LOW는 폭만으로 제외하지 않습니다. ISR과 메인 루프가 동일한 잠금으로 상태를 공유하고 루프가 늦어져도 다음 LOW에서 이전 통과를 확정합니다.

SPD 설정 표시는 `high_us=1000`입니다. raw/R은 원시 HIGH 진입 수, pulses/A는 확정된 통과 수입니다. EDGE의 `candidate=2`는 HIGH 안정화를 기다리는 후보이며 최종 수락이 아닙니다. 0은 후보 없는 에지입니다. 기존 accept 필드는 제거했으며 정지 후 전환 로그 출력은 유지합니다.

1ms는 시험용 조건입니다. 중복 신호 사이 HIGH가 1ms 이상이면 별도 통과로 집계되므로 모든 중복을 제거하지는 못합니다. 정상 HIGH도 1ms 미만인 고속에서는 누락될 수 있습니다. 초기화 후 한 방향으로 정확히 10바퀴 돌려 A=10인지 확인한 뒤 기준 속도와 비교해야 합니다.


사용자 요청으로 PCNT에서 단순 attachInterrupt 방식으로 전환했다. v0.10.9은 외경 19mm·지름 1.5mm 구멍 1개 롤러를 기준으로 한다. 구멍 크기는 환산식에 사용하지 않는다.

## 이전 구현 참고(판정 조건은 위 v0.10.9 설명 우선)

## 입력·집계

- G5 INPUT_PULLUP, attachInterrupt(digitalPinToInterrupt(5), speedPulseIsr, CHANGE).
- 가림=HIGH(LED 꺼짐), 열림=LOW(LED 켜짐). 상승만 세므로 1펄스/회전이다.
- ISR은 micros와 digitalRead로 시각·레벨을 읽고 portMUX 임계 구역에서 원시 카운터를 증가시킨다. 첫 펄스 또는 직전 유효 펄스 이후 1000μs 이상이면 유효 카운터도 증가시킨다. 거부된 펄스는 기준 시각을 갱신하지 않는다. 입력 레벨도 읽어 양쪽 전환을 기록한다. 속도 계산·시리얼 출력은 없다.
- 메인 루프에서 millis 기준 최소 500ms 간격으로 누적값과 시각을 원자적으로 스냅샷한다. 카운터를 구간마다 지우지 않아 읽기/초기화 사이 펄스 유실을 피한다.
- RPM = 펄스 × 60000 / 1 / 실제 경과 ms. km/h = 롤러 RPM × π × 19mm × 60 / 1000000.
- unsigned 차분으로 카운터와 millis 오버플로를 처리한다. 지연된 구간도 실제 경과 시간으로 계산한다.

## 조작·전력

앞쪽 버튼 짧게/길게 모두 초기화한다. 필터 전환은 제거했다. 모드 이탈·화면 off 시 detachInterrupt하고, 진입·기상 시 초기화 후 다시 연결한다. USB 연결 시 감광·슬립 금지 정책을 유지한다. SPEED에서 마이크·IMU·자력 ADC·FFT를 실행하지 않는다. CPU 80MHz를 유지하며 외부 센서 전원은 별도로 끄지 않는다.

## 출력·시험

화면 IRQ/R(원시 누적)/A(유효 누적)/IN:H,L 및 km/h. 시리얼은 메인 루프에서 약 1초마다 비차단 큐로 출력한다:

```text
SPD src=IRQ edge=RISING on=1 pin=L high_us=1000 raw=156 pulses=78 total_raw=156 total=78 dt_ms=500 rpm=9360.0 kmh=33.52
```

rpm은 롤러 RPM이다. dt_ms는 ms이므로 이전 PCNT 버전 dt(μs)와 구분한다. pin은 표시만 하며 집계에 사용하지 않는다. 실제 고속 검증은 USB 연결 후 정지→저속→고속 구간을 구분해 수행해야 한다. 이 변경만으로 센서 자체의 출력 지연 또는 펄스 누락이 해결됐다고 단정할 수 없다.

## 검증

bash tests/run-host-tests.sh 및 arduino-cli compile --fqbn m5stack:esp32:m5stack_sticks3 M5stickS3-motor-checker.

실제 스케치를 모의 보드에서 실행해 RISING만 집계, HIGH 유지·하강 중복 방지, 19mm 기준 알려진 펄스의 속도 환산과 5/60/120/1000μs HIGH 모의 입력, 연속 집계, millis·카운터 래핑, 버튼·스톱워치 보존, 모드·절전·USB 및 센서 격리를 검증한다. 호스트 테스트는 실기기의 GPIO IRQ 처리 지연이나 전기 파형을 재현하지 않는다. 실기기 업로드는 별도다.

### v0.10.9 중복 펄스 시험

19mm·구멍 1개 기준을 유지한다. 정지 상태에서 앞쪽 버튼으로 초기화하고 구멍을 센서 경계에 걸쳐 왕복하지 않도록 한 방향으로 10바퀴 돌린 뒤 0.5초 이상 기다린다. 화면 A 및 로그 total이 10인지 확인한다. R/total_raw가 더 크면 1ms 미만 추가 에지가 제거된 것이다. A도 10보다 크면 더 긴 간격의 중복 또는 실제 추가 통과가 있어 추가 진단이 필요하다. 시리얼은 1초 간격의 최근 구간만 보여주므로 raw/pulses를 더하지 말고 누적값을 사용한다. 1ms 임계값은 이론상 약 214.9km/h 이상에서 정상 펄스도 제외할 수 있으며 실측 최대 속도를 보장하지 않는다.

검증 결과: 기존 회귀·SPEED 호스트 테스트 통과. 10회 통과에 원시 40개/유효 10개 모의 채터링, 유효 에지 기준 간격 및 micros 래핑 검증 포함. M5StickS3 빌드 통과(프로그램 1,190,643 bytes, 정적 메모리 63,432 bytes). 실기기 업로드·정확도 시험은 아직 수행하지 않았다.

### v0.10.9 전환 시각 진단

인터럽트를 CHANGE로 설정해 LOW/HIGH 전환을 기록하되 속도는 HIGH 진입에만 기존 1ms 간격 필터를 적용한다. ISR은 시간·레벨·수락 여부를 128개 고정 링 버퍼에 저장하며 출력하지 않는다. 마지막으로 포착한 전환 이후 1초간 전환이 없고 시리얼이 연결된 경우 최근 128개를 별도 스냅샷으로 복사한 뒤 공유 비차단 큐에서 한 줄씩 출력한다. 회전이 다시 포착되면 전환 로그 출력을 보류하며 새 버퍼 기록은 계속한다. 포착되지 않는 고속 입력도 무전환으로 판단될 수 있어 기계적 정지를 보장하지 않는다.

```text
EDGE begin seq=20 kept=20 omitted=0 unit=us
EDGE i=0 t=100000 prev=? dt=0 level=L candidate=0
EDGE i=1 t=100251 prev=L dt=251 level=H candidate=2
EDGE end seq=20
```

`t`는 micros 기준 시각(약 71분마다 래핑), `dt`는 직전 기록 레벨의 유지 시간(μs), `level`은 이번 전환 후 읽은 레벨이다. `accept=1`은 속도 펄스로 수락한 HIGH, 0은 LOW 또는 필터에서 제외된 HIGH다. 첫 줄은 이전 전환을 모르므로 prev=? dt=0이며 실제 폭 0을 뜻하지 않는다. omitted는 초기화 후 발생한 전환 중 해당 스냅샷에 포함되지 않은 수다. 같은 스냅샷은 반복 출력하지 않는다. 장시간 회전 시 최근 128개만 남으므로 한 바퀴씩 돌린 뒤 멈추는 시험이 적합하다.

시험: USB 연결·시리얼 115200 → 앞쪽 버튼 초기화 → 한 방향으로 1바퀴 → 1초 이상 정지 → EDGE begin부터 end까지 수집. A가 2 증가하는 회전과 1 증가하는 회전의 로그를 비교한다. 마지막 줄까지 송신을 기다린다. 모드 변경·초기화·절전은 저장된 진단을 초기화한다. ISR 시각과 레벨 읽기는 실제 파형을 완벽히 재현하지 않으므로 짧은 펄스는 놓칠 수 있다. 이 버전은 진단용이며 중복 검출 해결을 확정한 버전은 아니다.

v0.10.9 검증: 기존 기능 및 통과 병합·1ms 경계·루프 지연·짧은 LOW·시각 래핑·초기화·시리얼·절전 모의 시험 통과. M5StickS3 컴파일 통과(프로그램 1,191,639 bytes, 정적 메모리 65,512 bytes). 실기기 업로드·정확도 검증은 별도입니다.
